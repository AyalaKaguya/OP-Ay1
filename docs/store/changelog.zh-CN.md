# v1.0.0（首个公开版本）

首个公开版本，围绕内置曲目 **ARYX（`aryx.s3m`）** 的播放与调音：

- 便携 C 模块引擎：S3M 解码 / 音序 / 混音，48 kHz 立体声输出
- 五页界面：WAVES、PATTERN、PLAYBACK、MIX、SECTION PADS
- 实时电平：每通道峰值表、2K 采样波形、主输出 dBFS 电平与削波指示
- MIX：dB 刻度推子、M/S 独奏联动、可滚动通道列表
- SECTION PADS：4×4 片段启动器，节拍闪烁排队、Pattern 边界切换、量化停止
- 稳定性：优先级继承引擎锁、UI 卡死看门狗、任务看门狗、崩溃前日志保留

已知限制：内置曲目为 12 Pattern / 12 通道，`0C`–`0F` 为空；合成器、采样器、
音序器与硬件扩展（外置 DAC、推子、键盘）在后续版本路线图中。

# Workstation device captures

Captured from ESP-Mosaico on 2026-10-27 through the workspace's Iris screenshot
command. The four 480×480 source PNGs are unchanged device captures; `overview.png`
places them in a labelled grid without resizing or redrawing the UI.

- `home.png`, `sampler.png`: final sampler-scroll/Home-motion firmware.
- `mixer.png`, `settings.png`: the preceding full-content firmware; those page
  renderers are unchanged in the sampler-scroll update.

The screens are paused at 5% master volume where displayed. This was a debug
setting, not the application's startup default. Runtime evidence and validation
boundaries are described in [the UI record](../../swipe-navigation.zh-CN.md).

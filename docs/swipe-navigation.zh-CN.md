# 手势导航与界面清理

2026-10-27；最新交互分支 `codex/sampler-scroll-home-motion`。

按用户指定交互替换主屏返回按钮和可点击页点，沿用共享 C 控件、渲染及 GSP 原生 backend。

- 从底部 40 像素起手，上滑至少 64 像素、纵向距离超过横向两倍时返回 HOME。
- 模块内取消左右切页；统一上滑回 HOME 后选择模块。HOME 保留左右翻动三页入口。
- 返回 HOME 时旧页面向上退出，HOME 从下方进入；包括完整顶部区域，不叠加固定主屏标题。
- HOME 页点悬浮于最终画面，只在成功左右翻主屏后显示 1.2 秒；点击不跳页，模块内不显示。
- 删除顶部／底部 HOME 图标和按钮、主屏翻页箭头、常驻页点与页码；存储入口移至 SETTINGS 右上角。
- 只有 HOME 显示活动项目名称、未保存标记和保存入口。其他页面去掉公共标题、项目栏和菜单，
  内容直接使用 0…439 行；设置页保留自身一层标题，音乐页面保留自身控件和实时数据。
- 删除常驻操作教学、实现说明和工程文件路径；保留控件标签、真实数值、单位与必要错误／状态。
- 采样库改为上下滚动列表：逻辑行距 72 像素（原 45 的 1.6 倍），卡片高 68 像素，
  名称和元数据为 2 倍字体；真实 PCM 波形位于每行右侧。删除下方独立波形和上下翻页按钮。
  内容拖动只滚动，短点选择；上下有界、释放吸附，底边上滑仍返回 HOME。

混音滚动／推子、合成器滑奏、波形编辑均保留原手势所有权。下拉抽屉优先处理关闭手势，
息屏后的第一次手势只唤醒，不穿透到 HOME 或演奏控件。返回 HOME 不重载工程、不停止歌曲，
只释放当前触摸音符和试听；未提交的采样编辑保留，后台 I/O 成功后不强制抢回原页面。
